# 排行榜阵容头像恢复（本地图标包）

日期：2026-10-23
起因：用户反馈「首页排行榜玩家的那些图片都没有了，可以加回来吗」——具体指每区阵容的三个角色头像。

## 为什么头像没了

上一轮改版为了让行高从 152px 降到 96px、并把首屏数据提前，把每区三个角色头像去掉了，只留「名字 + 品质 + 战力」文字。
真正的原因不是设计取舍，而是**原图太重**：

| | 原图 | 页面显示尺寸 |
| --- | --- | --- |
| 角色头像 `image/rolecharacter/` | 1024×1024 WebP，40–150KB | 18–48px |
| 辅助机 `image/rolepartner/` | 同上 | 16px |
| 玩家头像 `image/roleplayersp/` | 同上 | 40px |

首页排行榜一屏 8 行 × 3 区 × 3 角色 = 72 张头像，按原图算要 5–10MB。

资源站不支持服务端缩放（`?x-oss-process=image/resize,w_64` 之类参数被忽略，返回的仍是 117KB 原图），
所以只能在本地预先缩一套。

## 做法：本地 96px 小图包

1. `scripts/sync-char-icons.mjs`
   - 从两份真实响应（`docs/perf/fixture-warzone-16.json`、`fixture-player.json`）里收集所有 `icon / cubIcon / portrait / frame` 路径；
   - 只取 `image/rolecharacter/`（118）、`image/rolepartner/`（15）、`image/roleplayersp/`（63）共 **196 张**；
     故意跳过 `image/icontools/`（358 张涂装/武器图标，只在弹窗里用，保持走原站）；
   - 用 `curl` 经系统代理 `127.0.0.1:7877` 并发 6 下载，最多 4 趟重试。
2. `scripts/resize-char-icons.py`：Pillow 居中裁成正方形 → 96×96 → WebP q80，输出到 `public/img/chars/`。
3. 生成 `src/api/charPack.generated.js`：196 条路径的 `Set` + `localIconPath()`，源码 7.8KB（gzip 约 1.3KB）。
4. `src/api/config.js` 的 `getImageUrl()` 变成「本地有就用本地，没有回落原站」——
   排行榜、玩家页 85 个头像、阵容/分析/历史弹窗全部自动受益，调用点一处没改。
5. `src/api/imageFallback.js` 对 `/img/chars/` 跳过「webp→png」兜底（本地没有 png 版，否则还要打一次 404）。
6. `vercel.json` 给 `/img/chars/(.*)` 加 `Cache-Control: public, max-age=31536000, immutable`。

> 为什么用 curl 而不是 node 的 fetch：本机直连 assets.huaxu.app 约一半请求 25–40s 不返回（浏览器里表现为图片一直不出现），
> 走系统代理后基本秒回；而 node 的 `fetch` 默认不读 `HTTPS_PROXY`，所以脚本直接调 `curl -x`。
> 重新生成时如果代理端口变了，用 `ICON_PROXY=http://127.0.0.1:xxxx node scripts/sync-char-icons.mjs --force`。

## 界面上的恢复

- 桌面行：`.zone-chars` 改成竖排三行「18px 头像 + 名字（定宽 56px）+ 品质 + 战力」，行高仍保持 96px。
- 手机行：卡片里每区分数下面加一排 15px 小头像，行高 96 → 112px。
- 顺手去掉页头 `更新于`：顶部数据条已经有「榜单刷新」，重复了。

## 体积与效果

| 项目 | 前 | 后 |
| --- | --- | --- |
| 单张图标 | 40–150KB（1024×1024） | 2–4KB（96×96 WebP） |
| `public/img/chars/` 全量 | — | 196 个文件，共 1.4MB |
| 首屏 72 个头像实际传输 | 约 5–10MB | **5KB**（实测 30 个请求，其余懒加载/命中缓存） |
| 主包 | 248.05KB / gzip 78.42 | 255.99KB / gzip 79.79（+7.9KB 就是路径表） |

实测（`node scripts/shot-local.mjs`，1440×900）：`firstRow.top = 550`，行高 96，72 张阵容头像 **全部走本地、全部解码成功、0 失败**。

## 后续

- 新增角色/皮肤时，重跑 `node scripts/sync-char-icons.mjs` 即可增量补齐（默认跳过已存在的小图）。
- 如果哪天资源站开了服务端缩放，可以改用 URL 参数，删掉这套本地包。
