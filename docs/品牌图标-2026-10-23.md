# 品牌图标替换：全站用上自己的 ico

日期：2026-10-23

## 起因

加载页和导航左上角原来是一个黑底白字的「含」字占位方块。用户提供了站点图标（`icon.ico`，256×256 的 Q 版含英立绘），要求 logo 类位置都用它。

## 素材与产物

- 源文件：`icon.ico`（单帧 256×256，内部其实是 PNG，119KB）。用 `scripts/make-brand.py`（Pillow）从中转出各种尺寸。
- 产出（都在 `public/img/`，构建时原样复制到站点根）：

| 文件 | 尺寸 | 体积 | 用在哪 |
| --- | --- | --- | --- |
| `brand-176.webp` | 176 | 9.5KB | 加载页图标（88 CSS px，2x 屏） |
| `brand-64.webp` + `brand-64.png` | 64 | 1.9KB / 9.5KB | 导航左上角（32 CSS px，webp 失败自动回 png） |
| `brand-180.png` | 180 | 56KB | `apple-touch-icon`（iOS 添加到主屏） |
| `brand-192.png` | 192 | 63KB | `<link rel="icon" type="image/png">`（Android/桌面浏览器） |
| `brand-256.png` | 256 | 95KB | `og:image`（分享卡片） |

## 改了哪里

1. **加载页**（`index.html`）：`.boot-mark` 从「黑底 + 含字」换成 88px 圆角图标块，图标写成 CSS 背景图（`background: #e6e9ee url(/img/brand-176.webp) center/cover`）——浏览器解析 CSS 时就会开始下载，不用等 JS；底色是浅灰兜底，图没到也不会出现空洞。手机端 72px。外层呼吸动画、光圈（已删除，改为投影）保留。
2. **导航**（`src/components/Nav.jsx` + `src/styles/app.css`）：`.nav-logo` 内改成 32px 图标（webp + `object-fit: cover`，1px 描边、9px 圆角），文字标题不变。
3. **图标声明**（`index.html`）：`favicon.ico` + 192 PNG + `apple-touch-icon`，并补了 `og:type/title/description/image` 与 `twitter:card`，分享到 QQ/微信时能出图。
4. **顺手修掉一个 404**：上一轮我把 `index.html` 的图标引用改成绝对路径 `/favicon.ico`，但文件之前只在仓库根目录、Vite 只从 `public/` 复制静态文件，于是**线上 `/favicon.ico` 是 404**（已验证）。现在把 `favicon.ico` 放进 `public/`，本地与线上都返回 `200 image/x-icon 10592`。

## 验证

```
curl -s -o /dev/null -w '%{http_code} %{content_type}\n' http://127.0.0.1:4173/favicon.ico
curl -s -o /dev/null -w '%{http_code} %{content_type}\n' http://127.0.0.1:4173/img/brand-192.png
```

- 6 个图标资源全部 200（ico 10.5KB、192 63KB、180 56KB、176 webp 9.5KB、64 webp 1.9KB、256 95KB）。
- 截图（`docs/ui-audit/v2/`）：`boot-icon-desktop.png`、`boot-icon-mobile.png`、`nav-brand-zoom.png`（3x 放大看边缘）、`home-icon-desktop.png`。
- 导航图标 32px 下仍是「一个彩色小方块」，细节看不清但识别度够；加载页 88px 才看得清立绘。

## 备注

- `docs/brand-source-256.png` 是从 ico 里剥出来的原始 256 PNG，重跑 `node scripts/make-brand.py` 可再生成全部尺寸。
- 图标是白底立绘，所以显示为「白底圆角卡片」而不是透明贴纸；如果要透明底，需要先抠图再生成一轮。
