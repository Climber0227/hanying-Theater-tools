# 线上站点问题清单（2026-10-24）

审计方式：Playwright 打开 https://jiatenghui.icu，5 个页面 × 桌面 1440×900 / 手机 390×844，采集截图、几何尺寸、控制台报错、失败请求与网络时序。脚本 `scripts/audit-live.mjs`、`scripts/audit-detail2.mjs`、`scripts/audit-geom.mjs`、`scripts/audit-ppc-probe.mjs`，产物在 `docs/ui-audit/audit2/`。

基础健康度：10 个「页面×视口」组合 **0 控制台报错、0 横向溢出、0 图片加载失败**（玩家页 90 张图全部解码成功，说明本地图标包在线上生效）。

## P0 功能性缺陷

### 1. 幻痛囚笼榜单只显示前 6 名，其余 94 名无法访问
- 实测：DOM 里 100 行，`.ranking-table` 的 `clientHeight = 580`、`scrollHeight = 7823`、`overflow-y: hidden`；最后一个行 `top = 8077`，而整页 `scrollHeight = 945`。
- 原因：`src/styles/ranking.css:508-515` 的 `.ranking-table { height: clamp(420px, calc(100vh - 320px), 820px); overflow-y: hidden; }` 是给首页虚拟列表定的，幻痛页 `src/components/PpcPage.jsx:140` 复用同一个类名渲染 100 行普通 DOM，直接被裁掉。
- 影响：幻痛榜单第 7–100 名永远看不到，页面也不出现滚动条。

### 2. 幻痛页直接输出 ISO 原始时间戳
- 页面显示：`2026-10-18T21:00:00Z ~ 2026-10-25T10:00:00Z 分区: 终极区 更新时间: 2026-10-23T16:05:00.001091Z`。
- 首页早已格式化成「10.18 — 10.25 · 2 小时前更新」，这里连 `Z` 和纳秒都带出来了；「分区」还与左侧下拉重复。

### 3. 我的页未登录点「同步分数」没有任何反馈
- 实测点击后 1.8s 内：无弹窗、无 toast、页面文案无变化，只是开始异步加载下面两个区块。
- 正确行为应是「请先登录」提示，或按钮直接置灰/变成「去登录」。

### 4. 我的页区块编号乱序
- DOM 顺序：使用引导（步骤 1/2/3）→ **2 我的战区** → **3 我的幻痛** → **1 账号 · 库街区** → **4 关注列表**。
- 「2、3」出现在「1」前面，且引导里的 1/2/3 与区块编号 1/2/3/4 是两套编号，读者会串。

### 5. 我的页加载态是两行裸文字
- 数据未到时渲染出「加载战区数据中…」「加载幻痛数据中…」，无卡片、无标题、无骨架，直接贴在页面背景上（截图 `detail-mine-full.png`）。
- 位置还在「1 账号」之上，第一眼像是页面坏了。

### 6. 幻痛首屏 7–10 秒空白
- 网络时序：`/api/huaxu?path=/servers/cn/ppc/current/4` **连续两次 502**，第三次才 200（上游 api.huaxu.app 不稳）。
- 期间页面是 600px 纯白 + 一个「加载中…」小胶囊，没有骨架屏；用户很容易以为卡死。

## P1 布局与一致性问题

### 7. 首页更新公告卡片压住排行榜
| 视口宽 | 卡片位置 | 排行榜左边缘 | 重叠 |
| --- | --- | --- | --- |
| 1280 | x=16, w=288 | x=24 | **280px** |
| 1440 | x=16, w=288 | x=64 | **240px** |
| 1600 | x=16, w=288 | x=144 | **160px** |
| 1920 | x=16, w=288 | x=304 | 0 |

1440 及以下会把「排名」列和前 3 行头像整块盖住；卡片本身可点（有 × 收起和条目链接），被覆盖区域的玩家行点不到。

### 8. 五个页面四种标题规格
- 首页：左对齐 `.page-head` + 副信息行；
- 玩家查询 / 幻痛囚笼：居中 28px（`.page-title`）；
- 更新日志：居中 22px，位置还被 hero 区推低；
- 我的：**完全没有页面标题**，一进页面就是「使用引导」卡片。

### 9. 我的页空态信息密度极低
- 两块「暂无数据」图表框（各约 150px）+「暂无关注」+「暂无查询记录」，首屏 900px 里有效信息不到 1/3。
- 玩家页两块卡都为空时（「暂无查询记录」「暂无关注」），**两张卡右上角都仍然显示「清空」按钮**，点了没有意义。

### 10. 幻痛页表头/行布局失衡
- 表头只有「排名 / 玩家 / 总分」三列，全部挤在左侧 400px 内，右边 1000px 纯空；行内容同样靠左，总分在中间悬着。
- 上方三张 BOSS 卡居中排列，下方排行榜左对齐，两套对齐基线混在同一页。

### 11. 幻痛面板顶部残留旧的彩色渐变线
- `.rankings::before` 的蓝→紫→橙渐变条只在幻痛页可见，首页新面板没有，观感像加载条。

### 12. 玩家页仍用橙色系
- 「历届阵容」按钮描边、「该玩家隐藏了角色详情」提示框都是橙色，与首页的黑/白/金体系冲突；站点现在实际存在两套配色。

### 13. 手机端悬浮物遮挡
- 更新公告 FAB（46×46 @ 330,746）压住最后一行总分数字（截图 `mobile-warzone-top.png`，`117,339,000` 被盖）。
- 广告浮层 342×305 固定在手机首屏中上部（按你的要求不动，仅记录）。
- 右下「反馈」胶囊 182×23 压住面板底部脚注。

### 14. 触控目标过小
| 元素 | 尺寸 |
| --- | --- |
| 手机顶部 tab | 64.8 × **33px** |
| 手机区卡「查看详情 →」 | 53 × **18px** |
| 桌面「查看详情 →」 | 64 × **20px** |
| 表头排序按钮 | 66 × **20px** |
| 表头筛选漏斗 | **18 × 18px** |

## P2 文案与细节

15. 首页「**★ 同阶**」标签太省略：桌面写作「同阶最高」，手机只剩两个字，且位置落在两个区之间，看不出属于哪个区。
16. 我的页「使用引导 / 三步开启」措辞生硬；第 3 步的「同步分数」是黑色主按钮，与已完成步骤没有视觉区分。
17. 玩家页输入框 placeholder 只有「输入玩家ID」，没说明 ID 在哪看；下方两张空卡占 300px 却零信息。
18. 更新日志 2026-08-08 单条 15 项，长列表没有折叠，整页 `scrollHeight = 2440`。
19. 全站没有页脚：免责声明、数据来源、联系方式只有右下角一个胶囊。
20. 幻痛页没有「参与人数 / 我的排名」等基本信息，与首页面板的信息密度差一截。

## 建议修复顺序

1. **P0-1、P0-2**（幻痛页裁切 + 时间戳）：两处都是小改动，收益最大。
2. **P0-3~5**（我的页未登录反馈、编号顺序、裸文字加载态）。
3. **P1-7**（公告卡片遮挡）：≥1760 常驻卡片，窄屏自动收成竖标。
4. **P1-8、9、12**（标题规格、空态、橙色系）：把玩家/幻痛/我的/日志四页统一到首页视觉系统。
5. 其余作为打磨项。
