# 首屏加载体验：加载页 + 骨架 + 零位移

日期：2026-10-23
范围：首屏进入、切页、数据加载中这三个「什么都还没有」的瞬间。

## 问题

1. **点进网站先白屏**。HTML 只有 570B、`<body>` 里只有一个空 `#root`，CSS（97KB）与 JS（248KB）都要下载完才有第一帧画面。弱网或冷启动时这段空白能持续 1–3 秒，看起来像「网站挂了」。
2. **切页只剩一行灰字**。`src/App.jsx` 的 Suspense fallback 是 `<div className="m1-placeholder">加载中…</div>`，chunk 没命中预取时（弱网 / 省流量模式会跳过预取）就这一行。
3. **数据到位时整页往下跳**。`ZoneCards` 在 `zones` 为空时 `return null`，所以三张战区卡是「数据到了才插进来」的，把它们下面的排行榜整体推下去 ~113px；页头副信息（第 N 周 / 日期 / 更新时间）也是数据到了才出现，标题区先矮 20px 再长高。

## 做了什么

### 1. 首屏加载页（`index.html` 内联，不依赖任何包）

- 写在 `<head>` 的内联 `<style>` + `<body>` 顶部的 `<div id="boot">`：从**首字节**就能画出来，不用等 CSS/JS。
- 视觉：56px 黑色圆角方块「含」（呼吸 + 外圈光圈）、标题、168×3 轨道里一段带拖尾的滑动条、下方提示文案。背景复刻 `theme.css` 的 `#eceff3` + 三层顶部色光，淡出时**不会跳色**。
- 文案随等待时间升级（内联脚本，React 挂载后清掉计时器）：3s「正在下载页面资源」、6s「数据源响应较慢，正在重试」、15s「网络似乎不太顺畅，可稍候或刷新」。
- 撤场在 `src/main.jsx`：`createRoot(...).render()` 之后 `dismissBoot()`，**双 `requestAnimationFrame`** 保证 React 真的画出第一帧，再加 `is-done` 淡出（260ms）后 `remove()`。挂载抛异常时提示改成「页面初始化失败，请刷新重试」，不会留一个永远转圈的画面。
- `prefers-reduced-motion` 下关掉呼吸/滑动/省略号动画。

### 2. 切页占位（`src/App.jsx` + `src/styles/app.css`）

`.m1-placeholder` 换成 `.page-loader`：22px 转圈（`border-top` 用主色）+ 「正在加载…」，44vh 居中。三档圆角/字号/颜色都走设计令牌。

### 3. 数据加载中的骨架与零位移

- `src/components/ZoneCards.jsx`：新增 `loading` prop。`zones` 为空且仍在加载时，渲染三张**与真实卡片同高**的占位卡（`--zone-accent` 色条、两条 `sk-line` 微光条），不再 `return null`。
- `src/styles/zone.css`：`.zone-card-skeleton` 桌面 `min-height: 113px`、手机 `95px`；`.sk-line` 微光动画（`prefers-reduced-motion` 关闭）。
- `src/styles/ranking.css`：`.page-meta` 加 `min-height: calc(var(--fs-13) * 1.5)`，标题区先留出一行高度。
- `src/components/WarzonePage.jsx`：把 `warzone.loading` 传给 `ZoneCards`。

## 验证

脚本 `scripts/shot-boot.mjs`（先 `npx vite preview --port 4173`），产物 `docs/ui-audit/v2/`：

| 场景 | 做法 | 结果 |
| --- | --- | --- |
| 加载页 | `page.route('**/*.js')` 扣住不放 | `#boot` 可见、文案「正在连接数据源」；放行后 `dismissedAfterMount: true`（自动移除） |
| 数据骨架 | 接口请求一直挂着 | 3 张占位卡 + 8 行骨架 + 面板标题「同步中…」，`#boot` 已消失 |

## 两个踩坑记录

- 扣住模块脚本时 `DOMContentLoaded` **永远不会触发**（模块脚本阻塞它），`page.goto(..., { waitUntil: 'domcontentloaded' })` 会 30s 超时；要用 `waitUntil: 'commit'` + `waitForSelector('#boot')`。
- Playwright **后注册的 route 优先**。先注册具体路径再注册通配，通配会把具体规则盖掉（表现为 mock 不生效、`.ranking-row` 等不到）。

## 回滚

- 加载页：删 `index.html` 里的 `<style>` 与 `#boot`，删 `src/main.jsx` 的 `dismissBoot()` 调用。
- 切页占位：`src/App.jsx` 的 `PAGE_FALLBACK` 换回一行文字即可。
- 骨架卡：`WarzonePage` 不传 `loading`（`ZoneCards` 会退回「无数据时返回 null」）。
