# 全站灵动化设计文档（风格统一）

> 状态：设计完成，待实现
> 日期：2026-08-08
> 背景：用户反馈——折线图弹窗（CurveModal）很灵动，其他页面"死板"、风格不一致
> 目标：把 CurveModal 的"灵动感"规律扩散到全站，风格统一

---

## 一、灵动感来源拆解（CurveModal 已验证的规律）

1. **动画即叙事**：阶段化入场——框架（区域/网格）→ 折线绘制 → 数据点弹出，动画讲述"数据如何出现"
2. **"绘制"而非"显示"**：stroke-dashoffset 画线、scale 0→1 点生长
3. **延迟递增（stagger）**：50-150ms 错峰，水波节奏
4. **物理感**：ease-out cubic-bezier(0.16,1,0.3,1)、轻微上移 12px、drop-shadow
5. **克制**：极淡网格、留白、少而精

---

## 二、设计方案（按感知度排序）

### 1. 全局动画工具类（theme.css）
```css
@keyframes fade-up {
    from { opacity: 0; transform: translateY(12px); }
    to   { opacity: 1; transform: none; }
}
@keyframes fade-in { from { opacity: 0; } to { opacity: 1; } }
.page-fade { animation: fade-in 0.35s ease both; }        /* 页面切换 */
.anim-in {                                               /* 通用入场 */
    animation: fade-up 0.5s cubic-bezier(0.16,1,0.3,1) both;
    animation-delay: var(--d, 0ms);
}
```

### 2. 页面切换过渡（App.jsx）
- 页面容器包一层 `<div className="page-fade" key={page}>`，key 变化触发重挂载 → 淡入
- 零成本，所有 tab 切换立即灵动

### 3. 弹窗内容 stagger（modals.css，零 JSX 改动）
```css
.modal-content > * { animation: fade-up 0.45s cubic-bezier(0.16,1,0.3,1) both; }
.modal-content > *:nth-child(2) { animation-delay: 0.06s; }  /* 1=关闭按钮不延迟 */
.modal-content > *:nth-child(3) { animation-delay: 0.12s; }
.modal-content > *:nth-child(4) { animation-delay: 0.18s; }
.modal-content > *:nth-child(n+5) { animation-delay: 0.24s; }
```
- 所有弹窗（6 个 + 历史战绩 + 更新日志弹窗类）自动获得内容渐次浮现
- 弹窗懒加载每次挂载重播 ✅

## 三、技术要点

1. **虚拟滚动行动画克制**：react-window 行复用会反复 mount/unmount，`CountUp` 只在 mount 时 0→值、值变化时滚动——不要给行加入场 fade（滚动时闪动）；行级灵动只靠数字滚动
2. **性能**：可见行 ~10 行 × 4 个 CountUp = 40 个 rAF 动画同时跑，700ms 内完成，60fps 无压力；弹窗动画是 CSS，零 JS
3. **prefers-reduced-motion**：`@media (prefers-reduced-motion: reduce)` 下禁用动画（无障碍，可选）
4. **动画时长统一**：入场 0.4-0.5s、数字 0.7s、缓动统一 `cubic-bezier(0.16,1,0.3,1)`——风格一致的来源
