## 三、refactor-react 分支（React 重构版）

### 已完成（提交记录）
| Milestone | 内容 |
|---|---|

| M3 | 弹窗迁移：分数分布（**Recharts 柱状图**）、阵容参考、阵容排行、单区分析、趋势曲线（**Recharts AreaChart**：平滑曲线+渐变填充+shadcn 风格 Tooltip） |
| M4 | 玩家查询（搜索/信息/角色列表/历史/关注，排行榜点击跳转已打通）、幻痛囚笼（boss+详情+榜单，注意 loadPpc 需 level 参数）、我的（绑定/关注/导入导出） |
| M5 | Electron 适配（dev 加载 5173，生产加载 dist-web）、Vercel 构建配置（buildCommand + outputDirectory: dist-web） |

### 关键差异与坑
- **react-window v2 与 v1 API 不同**：`FixedSizeList` → `List`（`rowCount`/`rowHeight`/`rowComponent`/`rowProps`），行组件通过 `rows[index]` 取数据（rowProps 传 rows 数组）
- **性能**：回调必须 `useCallback` 稳定（react-window 对 rowProps 浅比较，不稳定会全行重渲染）；`ZoneCell` 已 memo；行图片 `decoding="async"`；overscan 2
- **shadcn 风格细节**：图表 Tooltip 卡片（圆角/指示器圆点/等宽数值）、弹窗入场动画（modal-fade/modal-pop）、曲线绘制动画、行 hover 按钮浮现、加载 shimmer 骨架屏、图例色块
- **样式**：`src/styles/` 下按组件拆分（theme/app/ranking/zone/modals/pages），沿用 CSS 变量体系
- 广告图放 `public/img/`（Vite 静态资源）

npm run build    # 构建到 dist-web/

## 五、已知边界与注意事项

1. **趋势数据仅本机**：localStorage 记录（30 分钟采样、200 条上限、换周清空），换设备/清缓存即丢失——后端化后解决
2. **排名变化差值仅本周生效**（30 分钟快照基线，`huaxu_wz_snap_{难度}`）
3. **阵容去重含阶级**：`getTeamKey`（角色ID-阶级排序拼接），位置互换视为同阵容
4. **段位隔离**：所有统计基于当前段位（难度）
5. **战区卡片机制名**：从 `description` 冒号前提取（困兽犹斗/祸不单行/斗众之势）
6. **PPC API 需要 level 参数**：`{ppc}/{week}/{level}?ranking=true`（React 版已修复）
7. **重构版构建输出 `dist-web/`**（旧 `dist/` 被运行中的桌面版占用，勿删进程中的目录）
