## 一、项目概述

战双帕弥什「含英牌战区数据工具」，纯前端 + Electron + Vercel Serverless。

- **前端**：原生 HTML/CSS/JS，无框架（`index.html` / `js/` / `css/`）
- **桌面端**：Electron（`electron-main.js` / `electron-preload.js`）
- **后端**：Vercel Serverless（`api/`），数据来自 `api.huaxu.app` 公开 API
- **数据存储**：localStorage（未登录）/ Supabase 云端（登录后）
- **数据源**：`https://api.huaxu.app/servers/cn/warzone|players|ppc/...`
- **资源**：`https://assets.huaxu.app/cn/...`

四个页面：战区数据、玩家查询、幻痛囚笼、我的。

## 二、本次会话新增/修改的功能

### 1. 角色阶级筛选（排行榜）
- 每区表头下 **3 个角色位下拉框**（S/SS/SSS/SSS+），精确匹配该区该位置的阶级
- 每区 **「全SSS」「全SSS+」快捷按钮**，一键将该区3个角色位统一设定
- 表头右侧 **「重置」** 清空所有筛选
- 排行榜角色行增加**品质标签**显示

### 2. 深色模式
- 导航栏右侧「深色/浅色」切换按钮，`localStorage` 记忆（key: `huaxu_theme`）
- `body.dark` 类 + CSS 覆盖，全站配色适配

### 3. 榜单搜索
- 工具栏搜索框，按玩家**名字或ID**实时过滤（与角色位筛选叠加）

### 4. 分数分布弹窗
- 「分数分布」按钮弹出弹窗，Tab 切换：**总分 / 三区各自**直方图
- 自动分10段，显示各段人数

### 5. 排名变化追踪（30分钟）
- 每30分钟自动刷新本周榜单，对比快照显示变化
- 排名：绿色 `↑N` / 红色 `↓N` / 灰色 `—`
- 总分 + **三个区各自**分数差值（绿+红-，用 `万/亿` 紧凑格式）
- 快照存 localStorage（key: `huaxu_wz_snap_{难度}`，version 3，30分钟基线）
- **仅本周生效**，浏览历史周时不显示差值

### 6. 阵容参考弹窗
- 「阵容参考」按钮弹出弹窗
- Tab1「最强阵容」：每区得分前三的玩家阵容
- Tab2「最常用阵容」：每区出场率 TOP5 阵容 + 占比条形图
- 区 Tab 切换（一行只显示一个区）
- **去重规则**：`getTeamKey` 按「角色ID-阶级」排序后拼接，位置互换视为同一阵容

### 7. 玩家历史战绩
- 玩家档案页「历史战绩」按钮，追溯该段位近100周的上榜记录（排名+分数表格）
- 可取消（关闭弹窗中断请求）

### 8. 单区分数分析弹窗
- 排行榜**每区的分数旁**有「分析」小按钮
- 弹窗显示：该玩家该区分数、阵容、**同阶级阵容最高分**对比
- 含最高分玩家的头像、名字、ID、阵容、战力
- 直接渲染在榜单上的标签：金色「同阶级阵容最高 {分数}」/ 红色「同阶级阵容最高 {分数} · 低{差}」

### 9. 战区卡片精简
- 卡片只显示：区名 + 怪物数量标签（单怪/双怪/群怪）+ 「详情」按钮
- 混合区额外显示子区增益名 chips
- 天气/增益/描述全部收进「详情」弹窗

### 10. 前三名奖牌样式
- 第1/2/3名显示**金银铜圆形奖牌** + 「冠军/亚军/季军」文字
- 冠军金牌带呼吸金光动画（`medal-gold`）
- 前三行有对应金/银/铜淡色渐变背景

### 11. 总分最高标注
- 该段位总分第一的玩家，总分下方显示金色呼吸「总分最高」标签

### 12. UI 放大
- 容器 `max-width: 1200px → 1440px`，各列/字号/间距放大
- 排行榜全局横滚（`overflow-x: auto`），各区列 `min-width: 240px`

### 13. 手机端适配
- 排行榜整表横滚，筛选控件缩小但功能完整
- 工具栏换行、导航换行、输入框全宽
- 仅缩小尺寸+横滚，不改变布局结构

## 五、注意事项 / 已知边界

1. **排名变化差值仅对本周生效**：`updateWzSnapshot` 只在加载本周数据时调用，历史周会清空 `wzPrevSnapshot`。
2. **快照 version 3**：旧格式快照自动失效重建，避免 score=0 导致「全分算上升」的 bug。
3. **阵容去重含阶级**：`[SSS+,SSS+,SSS]` 与 `[SSS+,SSS+,SSS+]` 视为不同阵容，位置互换视为相同。
4. **段位隔离**：所有统计（分布/阵容/最高分/差值）基于当前选择的段位（难度），不同段位分数不可比。
5. **历史战绩限制**：只能查玩家**进入 TOP100** 的周，且仅查当前段位、近100周。
6. **阵容参考「最强阵容」**：按区得分排序去重取前3，基于全量榜单。
