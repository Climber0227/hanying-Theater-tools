## 一、项目概述

战双帕弥什「含英牌战区数据工具」。**双分支并行**：

| 分支 | 说明 | 状态 |
|---|---|---|
| `main` | 原生 HTML/CSS/JS 版 | 线上已被 refactor-react 取代（Promote） |
| `refactor-react` | React 18 + Vite 重构版 | ✅ **已上线（jiatenghui.icu，2026-08-08 Promote）** |

- **前端（main）**：原生（`index.html` / `js/` / `css/`）
- **前端（refactor-react）**：React 18 + Vite（`src/`，构建产物 `dist-web/`），dev 端口 5173
- **桌面端**：Electron（生产加载 `dist-web/index.html`，开发加载 5173）
- **后端**：Vercel Serverless（`api/`：auth/user-data/trends/curve/proxy/visit）
- **存储**：localStorage（趋势/快照/历史/关注/绑定/分数/库街区 token）；Supabase（`users`/`sessions`/`user_data`）
- **数据源**：`api.huaxu.app`（榜单），资源 `assets.huaxu.app`；**`api.kurobbs.com`（库街区官方接口，浏览器直连，CORS 已验证开放）**

四个页面：战区数据、玩家查询、幻痛囚笼、我的 + 更新日志。

**部署方式（重要）**：项目 Git 集成的 `productionBranch` 仍是 `main`（Vercel REST API 不支持修改，需网页 Settings → Git 改）。推送 `refactor-react` 只触发 **preview** 部署；上线需在 Vercel Deployments 手动 **Promote to Production**。**建议改 Production Branch 为 `refactor-react` 一劳永逸，或每次上线后手动 Promote。**

### 库街区账号体系（2026-08-08 新增，新会话必读）

**接口封装**：`src/api/kurobbs.js` —— 浏览器直连 `api.kurobbs.com`（CORS 开放，已验证），无签名/加密，只需模拟 App 请求头（`source`/`devcode`/`User-Agent`）。参考开源 PGRUID / XutheringWavesUID（`PGRUID-main/` 目录为参考项目，未入库）。

**核心链路**：
- 绑定：手机号 + 极验滑块（captchaId `ec4aa4174277d822d73f2442a165a2cd`）→ `POST /user/getSmsCodeForH5` 发码 → `POST /user/sdkLoginForH5` 拿 token（JWT，会过期 code 220）
- 同步：**先调 `/haru/roleBox/refreshData`（强制刷新，等同 App 打开页面，解决缓存旧成绩）** → `/gamer/role/list`（角色列表，含 serverId）→ `/haru/roleBox/area`（战区）+ `/haru/roleBox/prisonerCage`（囚笼）
- 已用：`/haru/roleBox/accountData`（账号勋阶/等级/头像，绑定区展示）、`/haru/roleBox/roleIndex`（角色战力，阵容对比用）
- 未用（参考 PGRUID-main）：`stronghold`（诺曼矿区）、`transfinite`（历战映射）、`roleDetail`（角色详情）、`halfOfYear`（半年资源）、`dailyData`、`baseData`、`getChipOverclocking`（芯片超频）、`characterFashion/weaponFashion`（涂装）

**数据流**（同步即保存）：
```
进入我的页 → 自动同步（10s 防抖，先 refreshData 刷新）→ 写入本周记录（week 去重）
记录结构：{ week, groupName(段位组), groupLevel, challengeTimes, total, totalRank, totalDiff,
           zones: [{ name, score, team:[{name,grade,id}], teamRank:{rank,total},
                     subs:[{name(子区名), score, fightTime, supportBuffs}],  // 子区明细（熵钟异数=猩红冰原+岩流深壑，各自分数/战斗时间）
                     mech(机制名), monster(怪数:困兽犹斗=单怪/祸不单行=双怪/其他=群怪) }] }
→ 本地 localStorage（my_wz_scores 等）+ 登录时推云端 user_data（wz_scores/ppc_scores）
```
- **历史记录行内自描述**：表头用通用"区1/区2/区3"（每周区名不同），行内显示区名 + 怪数标签 + 子区名；周列显示区间日期（`2026.8.3~8.9`，由 timestamp 推算周一~周日）
- **旧记录补齐**：进入我的页对缺 mech/monster/subZones 的记录按周请求源站 API 补齐（`warzone/{week}/{difficulty}`，week 为绝对周号 488~582）

**账号安全**（已实现）：
- 用户名 2-20 位字母数字；密码 6-20 位任意字符（scrypt 加盐哈希）
- 登录防抢注（不自动注册）、连续失败 5 次锁 15 分钟、登出服务端删 session
- 忘记密码：库街区短信验证码验证身份（**发码走后端代理 `send_reset_code`，手机号全程脱敏不泄露**）
- 库街区绑定**归属账号**（`kurobbs_bound_user`）：换账号登录自动作废设备绑定防串号；退出清除有归属绑定（重新登录原账号从云端恢复）

**本周分数卡片 + 对比**：
- 本周分数卡（统计：总分/挑战次数/段位评价 + 各区：挑战/波次/机制名/阵容按钮）
- 阵容二级弹窗（buff 分组，角色：头像/阶级/元素/职业/武器超频/辅助机/芯片）
- **对比榜单**：按 `groupName+groupLevel` 自动匹配难度（`DIFFICULTY_OPTIONS` 映射），可切换更高/更低；同阵容组完整对比（角色头像/阶级/战力 bp），定位我的排名；晋级前100差距

**趋势图**（复用 `CurveModal.jsx` 导出的 `CurveChart`，新增 showTotal 总分线 + compact 小图模式）：

### 技术要点（新会话必读）

**react-window v2 用法（与 v1 不同）**
- `import { List } from 'react-window'`（无 FixedSizeList）
- 用 `rowCount` / `rowHeight` / `rowComponent` / `rowProps`，行组件通过 `rows[index]` 取数据
- **rowProps 浅比较**：回调必须 `useCallback` 稳定，否则滚动全行重渲染（已处理：RankingPanel 的 openAnalysis/openTrend）

**性能现状**
- 虚拟滚动：滚动 6000px 0 长任务 ✅
- 代码分割：页面（Player/Ppc/Mine）+ 弹窗（含 Recharts）已 `React.lazy`，首屏只加载排行榜核心
- 行图片 `decoding="async"`、overscan 2、ZoneCell memo
- ⚠️ **构建 chunk 警告**：主包 648KB（gzip 190KB），Recharts 已拆到弹窗 chunk；如需再优化可把 `react-window`/`recharts` 显式分包（`manualChunks`）

**shadcn 风格视觉细节（已实现）**
- 图表 Tooltip 卡片（圆角/指示器圆点/等宽数值）、弹窗入场动画、曲线绘制动画、行 hover 按钮浮现、加载骨架屏、图例色块
