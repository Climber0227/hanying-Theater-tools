## 一、项目概述

战双帕弥什「含英牌战区数据工具」。**双分支并行**：

| 分支 | 说明 | 状态 |
|---|---|---|
| `main` | 原生 HTML/CSS/JS 版 | 线上已被 refactor-react 取代（Promote） |
| `refactor-react` | React 18 + Vite 重构版 | ✅ **已上线（jiatenghui.icu，2026-08-08 Promote）** |

- **前端（main）**：原生（`index.html` / `js/` / `css/`）
- **前端（refactor-react）**：React 18 + Vite（`src/`，构建产物 `dist-web/`），dev 端口 5173
- **桌面端**：Electron（生产加载 `dist-web/index.html`，开发加载 5173）
- **后端**：Vercel Serverless（`api/`）
- **存储**：localStorage（趋势/快照/历史/关注/绑定/分数）；Supabase（用户账号 `users`/`sessions`）
- **数据源**：`api.huaxu.app`，资源 `assets.huaxu.app`

四个页面：战区数据、玩家查询、幻痛囚笼、我的 + 更新日志。

**部署方式（重要）**：项目 Git 集成的 `productionBranch` 仍是 `main`（Vercel REST API 不支持修改，需网页 Settings → Git 改）。推送 `refactor-react` 只触发 **preview** 部署；上线需在 Vercel Deployments 手动 **Promote to Production**。**建议改 Production Branch 为 `refactor-react` 一劳永逸，或每次上线后手动 Promote。**

### 技术要点（新会话必读）

**react-window v2 用法（与 v1 不同）**
- `import { List } from 'react-window'`（无 FixedSizeList）
- 用 `rowCount` / `rowHeight` / `rowComponent` / `rowProps`，行组件通过 `rows[index]` 取数据
- **rowProps 浅比较**：回调必须 `useCallback` 稳定，否则滚动全行重渲染（已处理：RankingPanel 的 openAnalysis/openTrend）

**性能现状**
- 虚拟滚动：滚动 6000px 0 长任务 ✅
- 代码分割：页面（Player/Ppc/Mine）+ 弹窗（含 Recharts）已 `React.lazy`，首屏只加载排行榜核心
- 行图片 `decoding="async"`、overscan 2、ZoneCell memo
- ⚠️ **构建 chunk 警告**：主包 648KB（gzip 190KB），Recharts 已拆到弹窗 chunk；如需再优化可把 `react-window`/`recharts` 显式分包（`manualChunks`）

**shadcn 风格视觉细节（已实现）**
- 图表 Tooltip 卡片（圆角/指示器圆点/等宽数值）、弹窗入场动画、曲线绘制动画、行 hover 按钮浮现、加载骨架屏、图例色块

**开发命令**
```
npm run dev      # dev server (5173)
npm run build    # 构建到 dist-web/
npm run preview  # 预览构建产物
```

6. **PPC API 需要 level 参数**：`{ppc}/{week}/{level}?ranking=true`
7. **登录在本地 dev 不可用**（AUTH_API 为空），部署后生效
8. **重构版构建输出 `dist-web/`**（勿删运行中进程占用的旧 `dist/`）
9. **Vercel 部署**：`vercel.json` 已配 `buildCommand: npm run build` + `outputDirectory: dist-web`；**productionBranch 仍是 main，上线需手动 Promote**
